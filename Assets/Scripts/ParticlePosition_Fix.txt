═══════════════════════════════════════════════════════════════════════
PARTICLE POSITION PRESERVATION - FIX
═══════════════════════════════════════════════════════════════════════

ISSUE:
═══════════════════════════════════════════════════════════════════════

Smoke particle system was set to position (0, 0, 3.77) in the editor,
but when entering Play mode, it was resetting to (0, 0, 0).

This happened because DrillHeatSystem was forcibly setting:
    smokeParticles.transform.localPosition = Vector3.zero;


CAUSE:
═══════════════════════════════════════════════════════════════════════

The UpdateDrillBitReferences() method was designed to re-parent particle
systems when drill bits are swapped. However, it was always resetting
the position to Vector3.zero, losing any custom offset you set.


SOLUTION:
═══════════════════════════════════════════════════════════════════════

Modified DrillHeatSystem to:

1. CAPTURE original positions and rotations at Start():
   ────────────────────────────────────────────────────────────────────
   smokeParticlesOriginalOffset = smokeParticles.transform.localPosition;
   smokeParticlesOriginalRotation = smokeParticles.transform.localRotation;
   
   This saves (0, 0, 3.77) and the original rotation.


2. RESTORE those positions when re-parenting:
   ────────────────────────────────────────────────────────────────────
   smokeParticles.transform.localPosition = smokeParticlesOriginalOffset;
   smokeParticles.transform.localRotation = smokeParticlesOriginalRotation;
   
   Now it uses the saved (0, 0, 3.77) instead of forcing (0, 0, 0).


═══════════════════════════════════════════════════════════════════════
BEHAVIOR
═══════════════════════════════════════════════════════════════════════

BEFORE FIX:
────────────────────────────────────────────────────────────────────────
Editor:     SmokeParticles position = (0, 0, 3.77)
Play mode:  Position resets to (0, 0, 0)  ✗ WRONG!


AFTER FIX:
────────────────────────────────────────────────────────────────────────
Editor:     SmokeParticles position = (0, 0, 3.77)
Play mode:  Position stays at (0, 0, 3.77)  ✓ CORRECT!


WHEN SWAPPING DRILL BITS:
────────────────────────────────────────────────────────────────────────
The particle systems will:
    1. Re-parent to the new drill bit
    2. Restore the original offset (0, 0, 3.77)
    3. Restore the original rotation
    
So smoke always appears at the correct position relative to each bit!


═══════════════════════════════════════════════════════════════════════
CODE CHANGES
═══════════════════════════════════════════════════════════════════════

ADDED PRIVATE FIELDS:
────────────────────────────────────────────────────────────────────────
private Vector3 smokeParticlesOriginalOffset;
private Vector3 burningSmellParticlesOriginalOffset;
private Quaternion smokeParticlesOriginalRotation;
private Quaternion burningSmellParticlesOriginalRotation;


MODIFIED Start():
────────────────────────────────────────────────────────────────────────
if (smokeParticles != null)
{
    smokeParticles.Stop();
    smokeParticlesOriginalOffset = smokeParticles.transform.localPosition;
    smokeParticlesOriginalRotation = smokeParticles.transform.localRotation;
}

if (burningSmellParticles != null)
{
    burningSmellParticles.Stop();
    burningSmellParticlesOriginalOffset = burningSmellParticles.transform.localPosition;
    burningSmellParticlesOriginalRotation = burningSmellParticles.transform.localRotation;
}


MODIFIED UpdateDrillBitReferences():
────────────────────────────────────────────────────────────────────────
BEFORE:
    smokeParticles.transform.localPosition = Vector3.zero;  ✗

AFTER:
    smokeParticles.transform.localPosition = smokeParticlesOriginalOffset;  ✓

HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

TIMELINE:
────────────────────────────────────────────────────────────────────────

1. EDITOR:
   You set SmokeParticles position to (0, 0, 3.77)

2. PLAY MODE STARTS:
   DrillHeatSystem.Start() runs:
       ✓ Captures position: smokeParticlesOriginalOffset = (0, 0, 3.77)
       ✓ Captures rotation: smokeParticlesOriginalRotation = (identity)

3. DURING PLAY:
   Particles stay at (0, 0, 3.77) ✓

4. DRILL BIT SWAP:
   UpdateDrillBitReferences() runs:
       ✓ Re-parents to new drill bit
       ✓ Restores position: (0, 0, 3.77)
       ✓ Restores rotation
       ✓ Smoke appears at correct offset on new bit!
