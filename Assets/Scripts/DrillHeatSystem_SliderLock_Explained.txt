═══════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

GRADUAL LOCK FORMULA:
────────────────────────────────────────────────────────────────────────

Heat Range:  warmColorThreshold (50%) → maxHeat (100%)
Lock Range:  0.0 (no force) → 1.0 (max force)

Formula:
    if (heat >= 50%)
    {
        lockForce = (heat - 50) / (100 - 50) * maxForce
        lockForce = (heat - 50) / 50 * 1.0
    }
    else
    {
        lockForce = 0
    }


EXAMPLE CALCULATION:
────────────────────────────────────────────────────────────────────────

Heat: 0%    → lockForce = 0.00  (no resistance)
Heat: 25%   → lockForce = 0.00  (no resistance)
Heat: 50%   → lockForce = 0.00  (just starting)
Heat: 60%   → lockForce = 0.20  (light resistance)
Heat: 70%   → lockForce = 0.40  (medium resistance)
Heat: 80%   → lockForce = 0.60  (strong resistance)
Heat: 90%   → lockForce = 0.80  (very strong)
Heat: 100%  → lockForce = 1.00  (FULLY LOCKED!)

CODE IMPLEMENTATION

void UpdateFingerLock()
{
    if (!enableFingerLock) return;
    
    if (internalGlove == null && hapticGlove != null)
        internalGlove = (SGCore.HapticGlove)hapticGlove.InternalGlove;
    
    if (internalGlove == null || !internalGlove.IsConnected()) return;
    
    float lockForce = 0f;
    
    // Calculate gradual lock from warm to max heat
    if (currentHeat >= warmColorThreshold)
    {
        float heatRange = maxHeat - warmColorThreshold;      // 100 - 50 = 50
        float heatAboveWarm = currentHeat - warmColorThreshold;  // e.g., 75 - 50 = 25
        lockForce = Mathf.Clamp01(heatAboveWarm / heatRange) * indexFingerLockForce;
        // lockForce = (25 / 50) * 1.0 = 0.5
        
        // Flag when fully locked
        if (lockForce >= indexFingerLockForce && !isFingerLocked)
        {
            isFingerLocked = true;
            Debug.Log("🔒 INDEX FINGER FULLY LOCKED!");
        }
    }
    else
    {
        // Below warm threshold = no force
        lockForce = 0f;
        
        if (isFingerLocked)
        {
            isFingerLocked = false;
            Debug.Log("🔓 INDEX FINGER RELEASED!");
        }
    }
    
    // Apply force to index finger (finger[1])
    float[] ffb = new float[5];
    ffb[1] = lockForce;  // Gradual force!
    
    internalGlove.QueueFFBLevels(ffb);
    internalGlove.SendHaptics();
}
