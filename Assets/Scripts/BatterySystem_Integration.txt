═══════════════════════════════════════════════════════════════════════
INTEGRATION WITH DrillHeatSystem
═══════════════════════════════════════════════════════════════════════

DrillHeatSystem now checks battery before allowing drilling:

CODE ADDED:
────────────────────────────────────────────────────────────────────────

[Header("Battery Integration")]
public DrillBatterySystem batterySystem;

In Update():
    bool isDrilling = triggerLogic.CurrentPressure > 0.1f;
    
    // NEW: Check battery before allowing drill to work
    if (batterySystem != null && !batterySystem.CanDrill())
    {
        isDrilling = false;  // Disable drilling if battery empty
    }


BEHAVIOR:
────────────────────────────────────────────────────────────────────────

Normal (battery > 0%):
    ✓ Trigger pulled → drill works
    ✓ Heat increases
    ✓ Battery drains

Battery empty (0%):
    ✗ Trigger pulled → nothing happens
    ✗ Heat stops increasing (starts cooling)
    ✗ Drill completely disabled

═══════════════════════════════════════════════════════════════════════
DATA FLOW
═══════════════════════════════════════════════════════════════════════

Every Frame:
────────────────────────────────────────────────────────────────────────

1. SG_TriggerLogic reads finger pressure
   ↓
2. DrillBatterySystem checks pressure > 0.1
   ↓
3. If drilling: battery drains (consumption rate)
   ↓
4. DrillHeatSystem checks if CanDrill()
   ↓
5. If battery empty: isDrilling = false
   ↓
6. BatteryLevelIndicator updates color based on charge
   ↓
7. Visual feedback: Battery pack glows green/yellow/red

API REFERENCE
═══════════════════════════════════════════════════════════════════════

DrillBatterySystem Public Methods:
────────────────────────────────────────────────────────────────────────

float GetChargePercentage()
    Returns 0.0 to 1.0 (0% to 100%)
    
bool IsEmpty()
    Returns true if battery is at 0%
    
bool IsLowCharge()
    Returns true if charge < mediumChargeThreshold (30%)
    
bool IsMediumCharge()
    Returns true if 30% ≤ charge < 60%
    
bool IsHighCharge()
    Returns true if charge ≥ 60%
    
void Recharge(float amount)
    Add amount (%) to battery
    Example: Recharge(25f) adds 25%
    
void FullRecharge()
    Sets battery to 100%
    
bool CanDrill()
    Returns true if drill can operate
    (used by DrillHeatSystem)


BatteryLevelIndicator Public Methods:
────────────────────────────────────────────────────────────────────────

void UpdateBatteryLevel(float chargePercentage)
    Updates visual color based on charge (0.0 to 1.0)
    Called automatically by DrillBatterySystem

RECHARGE STATION EXAMPLE:
────────────────────────────────────────────────────────────────────────

using UnityEngine;

public class DrillCharger : MonoBehaviour
{
    public DrillBatterySystem drillBattery;
    public float rechargeRate = 10f;
    
    void Update()
    {
        if (IsNearCharger())
        {
            drillBattery.Recharge(rechargeRate * Time.deltaTime);
        }
    }
    
    bool IsNearCharger()
    {
        // Your logic here
        return true;
    }
}


REPLACEABLE BATTERY EXAMPLE:
────────────────────────────────────────────────────────────────────────

using UnityEngine;

public class BatteryReplacement : MonoBehaviour
{
    public void OnBatterySwapped()
    {
        DrillBatterySystem battery = GetComponent<DrillBatterySystem>();
        battery.FullRecharge();
        Debug.Log("New battery installed!");
    }
}


UI DISPLAY EXAMPLE:
────────────────────────────────────────────────────────────────────────

using UnityEngine;
using UnityEngine.UI;

public class BatteryUI : MonoBehaviour
{
    public DrillBatterySystem battery;
    public Slider batterySlider;
    public Text batteryText;
    
    void Update()
    {
        float charge = battery.GetChargePercentage();
        batterySlider.value = charge;
        batteryText.text = $"{charge * 100:F0}%";
    }
}
