ISSUE 1: Smoke Particles Stay on Old Drill Bit
═══════════════════════════════════════════════════════════════════════

PROBLEM:
────────────────────────────────────────────────────────────────────────
When swapping drill bits, the smoke and burning smell particles remain
at the original drill bit location instead of moving to the new one.

ROOT CAUSE:
────────────────────────────────────────────────────────────────────────
Particle systems are GameObjects with Transform components. When created
as children of a specific drill bit, they stay attached to that drill bit
even when you swap to a different bit.

SOLUTION:
────────────────────────────────────────────────────────────────────────
The DrillHeatSystem now automatically moves the particle systems to the
new drill bit when swapping.

HOW IT WORKS:
────────────────────────────────────────────────────────────────────────
1. When drill bit changes, UpdateDrillBitReferences() is called
2. The particle GameObjects are re-parented to the new drill bit
3. Local position is reset to (0, 0, 0)
4. Particles now emit from the new drill bit location

SETTINGS:
────────────────────────────────────────────────────────────────────────
In DrillHeatSystem Inspector:
    
    [Particle Effects]
    ☑ Move Particles With Drill Bit  ← Must be checked!
    
If unchecked, particles will stay in their original location.
Only uncheck if you want particles fixed to DummyDrill-Rigged.

VERIFICATION:
────────────────────────────────────────────────────────────────────────
1. Press Play
2. Heat up the drill until smoke appears
3. Swap to different drill bit
4. Check Hierarchy:
   
   Before swap:
   └─ 3mm drill bit
      └─ SmokeParticles ← Here
      └─ BurningSmellParticles ← Here
   
   After swap to 5mm:
   └─ 5mm drill bit
      └─ SmokeParticles ← Should move here!
      └─ BurningSmellParticles ← Should move here!

TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────
□ Check "Move Particles With Drill Bit" is enabled
□ Make sure smokeParticles reference is assigned
□ Make sure burningSmellParticles reference is assigned
□ Verify particles are not set to "Play On Awake"
□ Check particle Simulation Space is "World" not "Local"

ISSUE 2: Temperature Not Increasing While Drilling
═══════════════════════════════════════════════════════════════════════

TEMPERATURE LOGIC EXPLANATION:
────────────────────────────────────────────────────────────────────────

The heat increases ONLY when BOTH conditions are true:
    1. Trigger pressure > 0.1 (10%)
    2. Drill bit is touching wood

Formula:
────────
Heat Increase Per Second = heatIncreaseRate * pressureMultiplier

Where:
    heatIncreaseRate = 8 (default, set in Inspector)
    pressureMultiplier = Lerp(0.5, 1.5, CurrentPressure)
    
Examples:
    Pressure 0%   → multiplier = 0.5 → 4°/sec  (but won't heat, pressure too low)
    Pressure 10%  → multiplier = 0.55 → 4.4°/sec
    Pressure 50%  → multiplier = 1.0 → 8°/sec
    Pressure 100% → multiplier = 1.5 → 12°/sec

CONDITIONS THAT MUST BE TRUE:
────────────────────────────────────────────────────────────────────────

✓ SG_TriggerLogic component exists on DummyDrill-Rigged
✓ CurrentPressure > 0.1 (trigger pulled at least 10%)
✓ IsTouchingWood = true (drill bit colliding with wood-tagged object)
✓ DrillHeatSystem component is enabled

IF ANY IS FALSE, HEAT WILL NOT INCREASE!

COMMON PROBLEMS:
────────────────────────────────────────────────────────────────────────

PROBLEM: Heat not increasing at all
CAUSES:
    □ SG_TriggerLogic is null or missing
    □ Not pulling trigger hard enough (< 10%)
    □ Table/wood object doesn't have "Wood" tag
    □ Drill bit collider not touching wood collider
    □ DrillHeatSystem component is disabled

PROBLEM: Heat increases very slowly
CAUSES:
    □ Low trigger pressure (increases slower)
    □ heatIncreaseRate set too low in Inspector
    □ Not continuously drilling (starting/stopping)

PROBLEM: Heat decreases instead of increasing
CAUSES:
    □ Not holding trigger
    □ Not touching wood
    □ Cool down rate higher than heat increase rate

DEBUG MODE:
────────────────────────────────────────────────────────────────────────

To see exactly what's happening:

1. Select DummyDrill-Rigged in Hierarchy
2. In DrillHeatSystem Inspector, find:
   
   [Debug]
   ☑ Enable Debug Logs  ← Check this!

3. Press Play
4. Open Console window (Ctrl+Shift+C)
5. Start drilling
6. Watch the logs:

   [DrillHeatSystem] Pressure: 0.85, TouchingWood: True, isDrilling: True, Heat: 42.3
   [DrillHeatSystem] Heat increasing by 0.133 per frame (multiplier: 1.28)

This tells you:
    - Pressure: Current trigger pressure (0 to 1)
    - TouchingWood: Is drill bit touching wood?
    - isDrilling: Is heat increasing?
    - Heat: Current heat value
    - Heat increase per frame
    - Pressure multiplier

WHAT TO LOOK FOR IN LOGS:
────────────────────────────────────────────────────────────────────────

GOOD (Heat should increase):
    Pressure: 0.75, TouchingWood: True, isDrilling: True ✓
    
BAD (Heat won't increase):
    Pressure: 0.05, TouchingWood: True, isDrilling: False ✗ (pressure too low)
    Pressure: 0.85, TouchingWood: False, isDrilling: False ✗ (not touching wood)
    
ERROR:
    "SG_TriggerLogic is null!" ✗ (component missing/disabled)

CHECKING WOOD TAG:
────────────────────────────────────────────────────────────────────────

The object you're drilling must have the "Wood" tag!

1. Select your Table/wood object in Hierarchy
2. Look at top of Inspector
3. Check "Tag" dropdown
4. Should say: "Wood"

If it says "Untagged", change it to "Wood"!

PATH TO CHECK:
    Table GameObject → Inspector → Tag: Wood ✓

CHECKING TRIGGER PRESSURE:
────────────────────────────────────────────────────────────────────────

To verify trigger is working:

1. Select DummyDrill-Rigged
2. Expand SG_TriggerLogic component
3. Look for "Latest Pressure" or similar field
4. In Play mode, pull trigger
5. Value should change from 0 to ~0.8-1.0

If it stays 0, trigger input is not working.

MANUAL HEAT TEST:
────────────────────────────────────────────────────────────────────────

To verify heat system works without VR:

1. Enter Play Mode
2. Select DummyDrill-Rigged
3. In DrillHeatSystem, manually set:
   - Current Heat: 50
4. Watch it decrease (cool down)
5. Set it to 80
6. Watch particles appear

This proves the visual system works.
If heat won't increase while drilling, it's an input/collision issue.

STEP-BY-STEP DIAGNOSIS:
────────────────────────────────────────────────────────────────────────

Follow this checklist:

□ Step 1: Enable Debug Logs
  └─ Check "Enable Debug Logs" in DrillHeatSystem

□ Step 2: Verify SG_TriggerLogic exists
  └─ DummyDrill-Rigged has SG_TriggerLogic component?
  └─ Component is enabled (checkmark on)?

□ Step 3: Verify trigger input
  └─ Pull trigger in VR
  └─ Check Console: Does "Pressure" value increase?
  └─ Should be > 0.1 when pulling trigger

□ Step 4: Verify wood detection
  └─ Drill into table
  └─ Check Console: Does "TouchingWood" say True?
  └─ If False, check table has "Wood" tag

□ Step 5: Verify drilling detection
  └─ While drilling with trigger pulled
  └─ Check Console: Does "isDrilling" say True?
  └─ If False, one of the conditions isn't met

□ Step 6: Check heat increase
  └─ When isDrilling = True
  └─ Check Console: Is heat increasing?
  └─ Should see "Heat increasing by X per frame"

□ Step 7: Check visual effects
  └─ When heat > 50, do particles appear?
  └─ When heat > 70, does smoke appear?
  └─ Does drill bit glow?

SETTINGS TO VERIFY:
────────────────────────────────────────────────────────────────────────

DrillHeatSystem component:
    Heat Increase Rate: 8 (higher = faster heating)
    Cool Down Rate: 3 (lower than increase rate)
    Max Heat: 100
    Burning Threshold: 50
    Overheating Threshold: 70

Table/Wood object:
    Tag: "Wood" (CRITICAL!)
    Layer: Can be anything
    Collider: Must have a collider component
    
Drill bit:
    Collider: Must have a collider component
    Rigidbody: Check if needed by SG_TriggerLogic

QUICK FIXES:
────────────────────────────────────────────────────────────────────────

Heat not increasing:
    → Enable Debug Logs
    → Check Console for "TouchingWood: False"
    → Add "Wood" tag to table

Heat increases too slow:
    → Increase "Heat Increase Rate" to 12-15
    → Pull trigger harder (higher pressure)

Heat never reaches thresholds:
    → Lower "Burning Threshold" to 30
    → Lower "Overheating Threshold" to 50

Particles don't move with drill bit:
    → Check "Move Particles With Drill Bit"
    → Verify particle references are assigned
