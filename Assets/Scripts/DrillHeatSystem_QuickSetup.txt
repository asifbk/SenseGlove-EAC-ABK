COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════

ISSUE: Drill won't start even when cool
────────────────────────────────────────────────────────────────────────
FIX: Check Current Heat < 100
     Check Safety Reset Threshold = 50 (not 90!)
     Check battery isn't empty


ISSUE: Glow appears immediately at 0%
────────────────────────────────────────────────────────────────────────
FIX: Check Warm Color Threshold = 50
     Restart Play Mode to apply code changes


ISSUE: Finger doesn't lock at 100%
────────────────────────────────────────────────────────────────────────
FIX: Check "Enable Finger Lock" is checked
     Check SenseGlove is connected
     Check drill is grabbed
     Check "Index Finger Lock Force" = 1.0


ISSUE: Finger doesn't release at 50%
────────────────────────────────────────────────────────────────────────
FIX: Wait for heat to drop to EXACTLY 50% or below
     Check "Safety Reset Threshold" = 50
     Enable Debug Logs to see unlock message
