KEY SETTINGS
═══════════════════════════════════════════════════════════════════════

DrillBatterySystem:
────────────────────────────────────────────────────────────────────────
Current Charge: 100        ← Start full
Drill Consumption: 2       ← Drain speed
☑ Disable When Empty       ← Drill stops at 0%
☐ Auto Recharge           ← Auto refill


BatteryLevelIndicator:
────────────────────────────────────────────────────────────────────────
Number Of Cells: 6         ← How many cell indicators
Cell Size: (0.01, 0.02, 0.008)  ← Size of each cell
Cell Spacing: 0.012        ← Gap between cells
Cell Offset: (0, 0, 0)     ← Position adjustment
☑ Use Emission            ← Makes cells glow
☑ Enable Blink When Low   ← Red cells blink
Blink Speed: 3            ← How fast
☑ Auto Create Cells       ← Creates cells automatically
