TRANSFORM DETAILS:
────────────────────────────────────────────────────────────────────────

Cell Offset (0.6, 0, 0):
    Positions the entire cell container 0.6 units to the RIGHT
    of the BatteryPack center (in local space)

Cell Rotation (0, 90, 0):
    Rotates the entire cell container 90 degrees around Y axis
    This makes cells arranged along Z axis instead of X axis

Cell Container Scale (5, 5, 5):
    Makes the entire cell container 5x larger
    Individual cells maintain their relative size (0.01, 0.02, 0.008)
    But world size becomes (0.05, 0.1, 0.04)

═══════════════════════════════════════════════════════════════════════
COORDINATE EXPLANATION
═══════════════════════════════════════════════════════════════════════

Position (0.6, 0, 0):
────────────────────────────────────────────────────────────────────────
X = 0.6   → Right (positive X)
Y = 0     → No vertical offset
Z = 0     → No forward/back offset


Rotation (0, 90, 0):
────────────────────────────────────────────────────────────────────────
X = 0     → No pitch
Y = 90    → Rotate 90° clockwise (top view)
Z = 0     → No roll

Effect: Cells that were along X axis now along Z axis


Scale (5, 5, 5):
────────────────────────────────────────────────────────────────────────
X = 5     → 5x wider
Y = 5     → 5x taller
Z = 5     → 5x deeper

Uniform scale - maintains proportions
