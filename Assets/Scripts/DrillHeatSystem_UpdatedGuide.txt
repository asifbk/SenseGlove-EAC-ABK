SENSGLOVE INTEGRATION
═══════════════════════════════════════════════════════════════════════

HOW FINGER LOCKING WORKS:
────────────────────────────────────────────────────────────────────────

The system uses SenseGlove's Force Feedback (FFB) API to PHYSICALLY
lock the index finger at 0 flexion (straight position):

1. At 100% heat:
   → Sends FFB command: indexFinger = 1.0 (full force)
   → Physically prevents finger from bending
   → User CANNOT bend finger even if they try

2. At 50% heat (cooled down):
   → Sends FFB command: indexFinger = 0.0 (no force)
   → Releases finger
   → User can bend finger normally again


FFB ARRAY STRUCTURE:
────────────────────────────────────────────────────────────────────────

float[] ffb = new float[5];
// [0] = Thumb      (not used)
// [1] = Index      ← LOCKED when overheated
// [2] = Middle     (not used)
// [3] = Ring       (not used)
// [4] = Pinky      (not used)

When locked:     ffb[1] = 1.0  (full lock force)
When unlocked:   ffb[1] = 0.0  (no force)


AUTO-DETECTION:
────────────────────────────────────────────────────────────────────────

The system automatically finds the SenseGlove hand:

1. Checks "Tracked Hand" reference in Inspector
2. If not set, looks for hand from SG_Grabable
3. Gets SG_HapticGlove component
4. Gets internal SGCore.HapticGlove for FFB

If detection fails, check debug logs:
    "Initialized. TrackedHand: True, HapticGlove: True" ✅ Good!
    "Initialized. TrackedHand: False, HapticGlove: False" ❌ Problem!

    Glow Color:      🟠 WARM (orange)
    Emission:        Starts glowing

Heat 50% → 100%:
    Glow Intensity:  0 → Max (gradually increases)
    Glow Color:      🟠 WARM → 🔴 HOT (orange to red)
    Emission:        Gradually brighter


CALCULATION:
────────────────────────────────────────────────────────────────────────

heatPercent = currentHeat / maxHeat
warmPercent = warmColorThreshold / maxHeat  (50/100 = 0.5)

if (currentHeat < warmColorThreshold):
    NO VISUAL EFFECTS
    
else:
    adjustedPercent = (heatPercent - warmPercent) / (1 - warmPercent)
    → This remaps 50-100% heat to 0-100% visual intensity
    
    Glow: 0 → maxGlowIntensity
    Color: warmColor → hotColor

CODE IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════

KEY METHODS:
────────────────────────────────────────────────────────────────────────

UpdateSafetyLock()
    - Checks if heat >= 100% → Lock drill
    - Checks if heat <= 50% → Unlock drill

UpdateFingerLock()
    - Checks if heat >= 100% → Lock index finger (FFB = 1.0)
    - Checks if heat <= 50% → Release index finger (FFB = 0.0)
    - Sends FFB commands to SenseGlove

UpdateVisualEffects()
    - Shows NO glow below warmColorThreshold (50%)
    - Shows glow from warmColor to hotColor (50% → 100%)
    - Adjusts intensity based on heat level


FINGER LOCK CODE:
────────────────────────────────────────────────────────────────────────

void UpdateFingerLock()
{
    if (!enableFingerLock) return;
    
    // Get internal glove if not cached
    if (internalGlove == null && hapticGlove != null)
        internalGlove = (SGCore.HapticGlove)hapticGlove.InternalGlove;
    
    if (internalGlove == null || !internalGlove.IsConnected()) return;
    
    // Lock at 100% heat
    if (currentHeat >= maxHeat && !isFingerLocked)
    {
        isFingerLocked = true;
        Debug.Log("🔒 INDEX FINGER LOCKED!");
    }
    // Unlock at 50% heat (warm threshold)
    else if (currentHeat <= safetyResetThreshold && isFingerLocked)
    {
        isFingerLocked = false;
        Debug.Log("🔓 INDEX FINGER RELEASED!");
    }
    
    // Apply force feedback
    float[] ffb = new float[5];
    if (isFingerLocked)
        ffb[1] = indexFingerLockForce;  // Lock index
    else
        ffb[1] = 0f;  // Release index
    
    internalGlove.QueueFFBLevels(ffb);
    internalGlove.SendHaptics();
}


CLEANUP ON EXIT:
────────────────────────────────────────────────────────────────────────

void ReleaseFingerLock()
{
    if (internalGlove != null && internalGlove.IsConnected())
    {
        float[] ffb = new float[5];  // All zeros
        internalGlove.QueueFFBLevels(ffb);
        internalGlove.SendHaptics();
        internalGlove.StopHaptics();
    }
}

Called on:
- OnDisable()
- OnDestroy()
- OnApplicationQuit()
