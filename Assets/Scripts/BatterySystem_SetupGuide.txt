═══════════════════════════════════════════════════════════════════════
DRILL BATTERY SYSTEM - SETUP GUIDE
═══════════════════════════════════════════════════════════════════════

WHAT IT DOES:
═══════════════════════════════════════════════════════════════════════

Adds a realistic battery system to your drill with:
    ✓ Visual battery level indicator (Green/Yellow/Red)
    ✓ Battery drains while drilling
    ✓ Drill stops working when battery is empty
    ✓ Optional auto-recharge or manual recharge
    ✓ Low battery blinking warning


COLOR INDICATORS:
═══════════════════════════════════════════════════════════════════════

🟢 GREEN    (100% → 60%)    High charge - drill works great
🟡 YELLOW   (60% → 30%)     Medium charge - still working
🔴 RED      (30% → 0%)      Low charge - blinking warning!
⚫ GRAY     (0%)            Empty - drill disabled!


═══════════════════════════════════════════════════════════════════════
SETUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════

STEP 1: Add Scripts to DummyDrill-Rigged
────────────────────────────────────────────────────────────────────────

1. Select "DummyDrill-Rigged" in Hierarchy
2. Add Component → DrillBatterySystem
3. This will also auto-find DrillHeatSystem


STEP 2: Add Indicator to BatteryPack
────────────────────────────────────────────────────────────────────────

1. Select "DummyDrill-Rigged/Model/BatteryPack" in Hierarchy
2. Add Component → BatteryLevelIndicator
3. It will automatically use the BatteryPack's MeshRenderer


STEP 3: Link Components
────────────────────────────────────────────────────────────────────────

1. Select "DummyDrill-Rigged" again
2. Find DrillBatterySystem component in Inspector
3. Drag "BatteryPack" GameObject to "Battery Indicator" field
   (Or leave empty - it will auto-find it!)


STEP 4: (Optional) Create Battery Material
────────────────────────────────────────────────────────────────────────

For best visual results, create a glowing material:

1. In Project → Assets/Materials
2. Right-click → Create → Material
3. Name it "BatteryIndicatorMaterial"
4. Set Shader: Universal Render Pipeline/Lit
5. Enable Emission:
   - Scroll down to "Emission"
   - Check the box to enable it
6. Set base color to white
7. Drag this material onto BatteryPack in the scene


THAT'S IT! Press Play and watch the battery drain!


═══════════════════════════════════════════════════════════════════════
SETTINGS EXPLAINED
═══════════════════════════════════════════════════════════════════════

DrillBatterySystem (on DummyDrill-Rigged):
────────────────────────────────────────────────────────────────────────

[Battery Settings]
  Current Charge: 100           ← Starting charge (100% = full)
  Max Charge: 100               ← Maximum battery capacity
  Drill Consumption Rate: 2     ← How fast battery drains (% per second)
  Idle Consumption Rate: 0.1    ← Slow drain when not drilling

[Battery Thresholds]
  High Charge Threshold: 60     ← Green above this (60%)
  Medium Charge Threshold: 30   ← Yellow above this (30%)
                                  Red below this (30%)

[Behavior]
  ☑ Disable Drill When Empty    ← Drill stops at 0%
  ☐ Auto Recharge               ← Automatically recharge over time
  Recharge Rate: 5              ← How fast it recharges (% per second)

[References]
  Battery Indicator: BatteryPack  ← Link to indicator component


BatteryLevelIndicator (on BatteryPack):
────────────────────────────────────────────────────────────────────────

[Visual Settings]
  Battery Renderer: MeshRenderer  ← Auto-assigned
  Material Index: 0               ← Which material to color
  ☑ Use Emission                  ← Enable glowing effect

[Battery Colors]
  High Charge Color: Green (0, 1, 0)
  Medium Charge Color: Yellow (1, 1, 0)
  Low Charge Color: Red (1, 0, 0)
  Empty Color: Dark Gray (0.2, 0.2, 0.2)

[Thresholds]
  High Charge Threshold: 0.6    ← 60% for green
  Medium Charge Threshold: 0.3  ← 30% for yellow/red

[Emission Settings]
  High Charge Emission: 2       ← Bright green glow
  Medium Charge Emission: 1.5   ← Medium yellow glow
  Low Charge Emission: 1        ← Dim red glow
  Empty Emission: 0             ← No glow when empty

[Animation]
  ☑ Enable Blink When Low       ← Blink when under 30%
  Blink Speed: 2                ← How fast it blinks

TIMELINE EXAMPLE
═══════════════════════════════════════════════════════════════════════

Battery Life (with default settings):
────────────────────────────────────────────────────────────────────────

Starting:       100% 🟢 Green - Full charge
After 20s:      60%  🟢 Green - Still good
After 35s:      30%  🟡 Yellow - Medium charge
After 40s:      20%  🔴 Red + Blinking - Low battery!
After 50s:      0%   ⚫ Gray - EMPTY! Drill stops

Total drilling time: ~50 seconds (with consumption rate = 2)


With Auto-Recharge Enabled:
────────────────────────────────────────────────────────────────────────

0s:   100% → Start drilling
50s:  0%   → Battery empty, drill stops
51s:  5%   → Recharging at 5% per second
60s:  50%  → Still recharging (blinking yellow)
70s:  100% → Fully recharged! (can drill again)

═══════════════════════════════════════════════════════════════════════
VISUAL BEHAVIOR
═══════════════════════════════════════════════════════════════════════

WHAT YOU'LL SEE:
────────────────────────────────────────────────────────────────────────

100% → 60%:  BatteryPack glows bright GREEN 🟢
              Smooth green emission

60% → 30%:   BatteryPack turns YELLOW 🟡
              Medium brightness

30% → 0%:    BatteryPack turns RED 🔴
              Starts BLINKING as warning!
              Blinks on/off every 0.5 seconds

0%:          BatteryPack turns DARK GRAY ⚫
              No glow, no emission
              Drill completely stops


BLINKING WARNING:
────────────────────────────────────────────────────────────────────────

When battery drops below 30%, the red light will blink:
    ⚫ OFF → 🔴 ON → ⚫ OFF → 🔴 ON → ⚫ OFF
    
This warns you: "BATTERY ALMOST EMPTY!"


═══════════════════════════════════════════════════════════════════════
INTEGRATION WITH HEAT SYSTEM
═══════════════════════════════════════════════════════════════════════

The battery system automatically integrates with DrillHeatSystem:

WHEN BATTERY DIES:
────────────────────────────────────────────────────────────────────────
    ✓ Drill stops working
    ✓ Heat stops increasing
    ✓ Drill cools down normally
    ✓ Haptic lock releases (if active)
    ✓ Smoke/particles stop

Battery empty takes priority over everything else!


═══════════════════════════════════════════════════════════════════════
MANUAL RECHARGE
═══════════════════════════════════════════════════════════════════════

You can add custom recharge triggers! Examples:

RECHARGE STATION (EXAMPLE CODE):
────────────────────────────────────────────────────────────────────────

Create a charging station that refills the drill:

using UnityEngine;

public class DrillCharger : MonoBehaviour
{
    public float rechargeRate = 10f;
    
    void OnTriggerStay(Collider other)
    {
        DrillBatterySystem battery = other.GetComponent<DrillBatterySystem>();
        if (battery != null)
        {
            battery.Recharge(rechargeRate * Time.deltaTime);
        }
    }
}


INSTANT RECHARGE BUTTON (EXAMPLE):
────────────────────────────────────────────────────────────────────────

public class RechargeButton : MonoBehaviour
{
    public DrillBatterySystem drillBattery;
    
    public void OnButtonPressed()
    {
        drillBattery.FullRecharge();
    }
}

WATCH IN PLAY MODE:
────────────────────────────────────────────────────────────────────────

1. Enter Play mode
2. Select DummyDrill-Rigged
3. Watch DrillBatterySystem component
4. "Current Charge" slider shows real-time battery level


MANUAL TESTING:
────────────────────────────────────────────────────────────────────────

Test low battery:
    1. Play mode
    2. Set Current Charge: 25
    3. BatteryPack should turn red and blink!

Test empty:
    1. Set Current Charge: 0
    2. BatteryPack should turn gray
    3. Try to drill - nothing happens!


═══════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

BATTERY COLOR NOT CHANGING:
────────────────────────────────────────────────────────────────────────
□ Check BatteryIndicator is on BatteryPack GameObject
□ Verify Battery Renderer is assigned
□ Make sure material has emission enabled
□ Try creating a new material for the battery

DRILL STILL WORKS WHEN EMPTY:
────────────────────────────────────────────────────────────────────────
□ Check "Disable Drill When Empty" is checked
□ Verify Battery System reference in DrillHeatSystem
□ Enable debug logs to see battery state

NO BLINKING WHEN LOW:
────────────────────────────────────────────────────────────────────────
□ Check "Enable Blink When Low" is checked
□ Verify charge is actually below 30%
□ Try increasing Blink Speed

BATTERY DRAINS TOO FAST:
────────────────────────────────────────────────────────────────────────
□ Reduce "Drill Consumption Rate" (try 1 or 0.5)
□ Or enable Auto Recharge

SUMMARY
═══════════════════════════════════════════════════════════════════════

Two components:
    1. DrillBatterySystem (on drill) - manages charge
    2. BatteryLevelIndicator (on battery pack) - shows colors

Colors:
    🟢 Green  = High (60-100%)
    🟡 Yellow = Medium (30-60%)
    🔴 Red    = Low (0-30%) + BLINKING
    ⚫ Gray   = Empty (0%)

Default: 50 seconds of drilling time, drill stops when empty!
