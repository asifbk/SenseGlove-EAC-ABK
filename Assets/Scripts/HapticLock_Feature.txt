═══════════════════════════════════════════════════════════════════════
HAPTIC LOCK FEATURE - OVERHEAT FINGER LOCK
═══════════════════════════════════════════════════════════════════════

WHAT IS IT?
═══════════════════════════════════════════════════════════════════════

When the drill overheats (reaches hot color at 90°), your index finger
gets LOCKED in a fully bent position (1.0 flexion) until the drill
cools back down to warm temperature (50°).

This creates realistic haptic feedback simulating:
    ✓ Drill motor seizing up from overheating
    ✓ Stuck trigger mechanism
    ✓ Physical resistance from heat damage
    ✓ Warning that you've overheated the drill

═══════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

NORMAL OPERATION (Temperature < 90°):
────────────────────────────────────────────────────────────────────────
    Flexion Range: 0.3 (start) to 0.5 (end)
    
    Your finger can bend:
        0.3 → Trigger starts responding
        0.5 → Trigger fully pressed (maximum bend allowed)
    
    You can freely bend and unbend your finger between these values.


OVERHEAT LOCK (Temperature ≥ 90°):
────────────────────────────────────────────────────────────────────────
    Flexion Range: 0.3 (start) to 0.3 (end) ← LOCKED!
    
    When temperature hits 90°:
        ✓ endFlexion immediately changes from 0.5 → 0.3
        ✓ Range becomes ZERO (0.3 to 0.3)
        ✓ Your finger CANNOT bend beyond 0.3
        ✓ Feels like hitting a hard stop/wall
        ✓ Finger stays locked until temperature drops below 50°
    
    While locked:
        - Cannot bend finger past 0.3 (start position)
        - SenseGlove forces finger to stay at minimum bend
        - Creates physical feedback of "frozen" trigger
        - Trying to pull trigger feels like it won't move


COOL DOWN (Temperature drops below 50°):
────────────────────────────────────────────────────────────────────────
    When temperature cools from 90° down to 50°:
        ✓ endFlexion changes back from 0.3 → 0.5
        ✓ Your finger can bend freely again
        ✓ Normal flexion range restored (0.3 to 0.5)
        ✓ Trigger responds normally

SETTINGS
═══════════════════════════════════════════════════════════════════════

In DrillHeatSystem Inspector:

[Haptic Feedback]
☑ Enable Haptic Lock           ← Turn feature on/off
Normal End Flexion: 0.5         ← Normal max bend (default)
Locked End Flexion: 1.0         ← Locked max bend (full)

DEFAULTS:
────────────────────────────────────────────────────────────────────────
Enable Haptic Lock: ✓ Checked (feature ON)
Normal End Flexion: 0.5 (standard trigger range)
Locked End Flexion: 0.3 (same as startFlexion = ZERO range = locked)

CUSTOMIZATION:
────────────────────────────────────────────────────────────────────────

Slightly less restrictive lock (small range allowed):
    Locked End Flexion: 0.35 (allows tiny bit of movement)

Complete freeze (no movement at all):
    Locked End Flexion: 0.3 (zero range)

Even tighter lock:
    Locked End Flexion: 0.0 (narrowest possible)

Disable feature entirely:
    ☐ Uncheck "Enable Haptic Lock"

═══════════════════════════════════════════════════════════════════════
PHYSICAL SENSATION
═══════════════════════════════════════════════════════════════════════

What the user feels:

WHEN LOCK ACTIVATES (temp hits 90°):
────────────────────────────────────────────────────────────────────────
    1. Range collapses from 0.3-0.5 to 0.3-0.3
    2. Finger CANNOT bend beyond 0.3
    3. Feels like hitting a hard wall
    4. Trigger won't move/pull
    5. Visual feedback: red glow + smoke confirms overheat

WHILE LOCKED:
────────────────────────────────────────────────────────────────────────
    1. Constant resistance preventing bending
    2. Feels "frozen" in place
    3. Trying to pull trigger does nothing
    4. Strong haptic reminder: "DRILL IS OVERHEATED!"

WHEN LOCK RELEASES (temp drops to 50°):
────────────────────────────────────────────────────────────────────────
    1. Range expands from 0.3-0.3 back to 0.3-0.5
    2. Finger can bend freely again
    3. Normal trigger response restored
    4. Visual: orange glow remaining, no smoke

═══════════════════════════════════════════════════════════════════════
TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════

HOW IT'S IMPLEMENTED:
────────────────────────────────────────────────────────────────────────

DrillHeatSystem.UpdateHapticLock() runs every frame:

    if (currentHeat >= hotColorThreshold && !isFlexionLocked)
    {
        // LOCK: Change trigger's end flexion to 0.3 (same as start)
        // This creates ZERO range, preventing any bending
        isFlexionLocked = true;
        triggerLogic.endFlexion = lockedEndFlexion;
    }
    else if (currentHeat < warmColorThreshold && isFlexionLocked)
    {
        // UNLOCK: Restore trigger's end flexion to 0.5
        isFlexionLocked = false;
        triggerLogic.endFlexion = normalEndFlexion;
    }

SG_TriggerLogic.endFlexion controls the maximum finger bend allowed.
- Normal: startFlexion=0.3, endFlexion=0.5 (range of 0.2)
- Locked: startFlexion=0.3, endFlexion=0.3 (range of 0.0 = frozen!)

When endFlexion equals startFlexion, there's NO range for movement,
effectively locking the finger at that position.

HYSTERESIS:
────────────────────────────────────────────────────────────────────────

Lock at:   90° (hotColorThreshold)
Unlock at: 50° (warmColorThreshold)

This 40° gap prevents rapid lock/unlock cycling as temperature
fluctuates near the threshold.

Without hysteresis:
    89° → unlock
    90° → lock
    89° → unlock   ← Annoying flickering!
    90° → lock

With hysteresis:
    90° → lock
    80° → still locked
    60° → still locked
    50° → unlock   ← Clean transition!

═══════════════════════════════════════════════════════════════════════
GAMEPLAY IMPLICATIONS
═══════════════════════════════════════════════════════════════════════

STRATEGY:
────────────────────────────────────────────────────────────────────────

Players must manage heat to avoid getting locked:
    ✓ Drill in short bursts to stay below 90°
    ✓ Release trigger periodically to cool down
    ✓ If locked, must wait ~13 seconds for cool down
    ✓ Creates tension and challenge

REALISM:
────────────────────────────────────────────────────────────────────────

Real drills can overheat and seize up:
    ✓ Motor gets stuck from heat expansion
    ✓ Trigger mechanism can jam
    ✓ Need to let it cool before continuing
    ✓ This simulates that realistic behavior

DIFFICULTY LEVELS:
────────────────────────────────────────────────────────────────────────

Easy (No lock):
    Enable Haptic Lock: ☐ Unchecked

Medium (Quick recovery):
    Heat Increase Rate: 5
    Cool Down Rate: 5
    → Lock lasts ~8 seconds

Hard (Slow recovery):
    Heat Increase Rate: 8
    Cool Down Rate: 2
    → Lock lasts ~20 seconds

Extreme (Very sensitive):
    Hot Color Threshold: 60
    Warm Color Threshold: 30
    → Locks earlier, takes longer to unlock

═══════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

FINGER NOT LOCKING:
────────────────────────────────────────────────────────────────────────
□ Check "Enable Haptic Lock" is checked
□ Verify temperature reaches 90°
□ Make sure SG_TriggerLogic reference is valid
□ Check SenseGlove glove is connected
□ Ensure grabable is grabbed (holding drill)

FINGER LOCKS BUT WON'T UNLOCK:
────────────────────────────────────────────────────────────────────────
□ Temperature must drop below 50° (not just below 90°)
□ Wait longer for cooling (default: ~13 seconds)
□ Check debug logs to see current temperature
□ Verify "Warm Color Threshold" is set to 50

LOCK TOO WEAK (Can still bend):
────────────────────────────────────────────────────────────────────────
□ Locked End Flexion should be 0.3 or lower (not higher!)
□ Check it's not set to 1.0 (that allows MORE bending!)
□ Try setting to 0.0 for maximum lock strength
□ Check SenseGlove battery level
□ Verify SenseGlove calibration
□ Try increasing FFB intensity in SenseGlove settings

LOCK TOO STRONG (Uncomfortable):
────────────────────────────────────────────────────────────────────────
□ Increase "Locked End Flexion" to 0.35 or 0.4
□ This allows tiny bit of movement while still restricting
□ Or disable feature: uncheck "Enable Haptic Lock"
□ Adjust SenseGlove FFB intensity globally
