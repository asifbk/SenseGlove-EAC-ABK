═══════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

AUTOMATIC CELL CREATION:
────────────────────────────────────────────────────────────────────────

When BatteryLevelIndicator.Start() runs:
    1. Creates parent GameObject "BatteryCells"
    2. Creates 6 cube primitives as children
    3. Positions them in a row
    4. Assigns glowing materials to each
    5. Stores references for updates

Hierarchy created:
    BatteryPack
    └── BatteryCells
        ├── BatteryCell_1
        ├── BatteryCell_2
        ├── BatteryCell_3
        ├── BatteryCell_4
        ├── BatteryCell_5
        └── BatteryCell_6


CELL POSITIONING:
────────────────────────────────────────────────────────────────────────

Cells are arranged horizontally in a row:

    cellSpacing = 0.012 (distance between cells)
    numberOfCells = 6
    
    Layout:
    [Cell1] [Cell2] [Cell3] [Cell4] [Cell5] [Cell6]
    <------- centered on BatteryPack ------->

Each cell position:
    float totalWidth = (numberOfCells - 1) * cellSpacing;
    float startX = -totalWidth * 0.5f;
    xPos = startX + (i * cellSpacing);


CHARGE LEVEL MAPPING:
────────────────────────────────────────────────────────────────────────

Battery charge (0-100%) → Number of lit cells:

    int activeCells = Mathf.CeilToInt(currentChargeLevel * numberOfCells);

Examples:
    100% charge → 6.0 → 6 cells lit
    83%  charge → 5.0 → 5 cells lit
    67%  charge → 4.0 → 4 cells lit
    50%  charge → 3.0 → 3 cells lit
    33%  charge → 2.0 → 2 cells lit
    17%  charge → 1.0 → 1 cell lit
    0%   charge → 0.0 → 0 cells lit


COLOR SELECTION:
────────────────────────────────────────────────────────────────────────

All active cells share the same color based on charge level:

    if (charge >= 60%):     🟢 Green
    elif (charge >= 30%):   🟡 Yellow
    elif (charge > 0%):     🔴 Red
    else:                   ⚫ Empty (dark gray)


MATERIAL UPDATES:
────────────────────────────────────────────────────────────────────────

Every frame (or when charge changes):
    1. Calculate how many cells should be lit
    2. For each active cell:
       - Set base color
       - Set emission color (color × intensity)
    3. For each inactive cell:
       - Set to empty color (dark gray)
       - Set minimal emission


BLINKING ANIMATION:
────────────────────────────────────────────────────────────────────────

When charge < 30% (low battery):
    1. Enable blinking in Update()
    2. Oscillate emission intensity using sine wave:
       blinkFactor = (sin(time * blinkSpeed) + 1) * 0.5
    3. Lerp emission between empty and full:
       currentEmission = Lerp(emptyEmission, baseEmission, blinkFactor)
    4. All active cells blink together


═══════════════════════════════════════════════════════════════════════
CODE STRUCTURE
═══════════════════════════════════════════════════════════════════════

FIELDS:
────────────────────────────────────────────────────────────────────────

Cell Configuration:
    int numberOfCells = 6
    Vector3 cellSize = (0.01, 0.02, 0.008)
    float cellSpacing = 0.012
    Vector3 cellOffset = (0, 0, 0)

Colors:
    Color highChargeColor = Green
    Color mediumChargeColor = Yellow
    Color lowChargeColor = Red
    Color emptyColor = Dark Gray

Emission:
    float highChargeEmissionIntensity = 3
    float mediumChargeEmissionIntensity = 2
    float lowChargeEmissionIntensity = 1.5
    float emptyEmissionIntensity = 0.2

Private:
    GameObject[] cellObjects
    Renderer[] cellRenderers
    Material[] cellMaterials
    float currentChargeLevel
    float blinkTimer


METHODS:
────────────────────────────────────────────────────────────────────────

void Start()
    - Calls CreateBatteryCells() if autoCreateCells enabled
    - Initializes to full charge (100%)

void CreateBatteryCells()
    - Removes old cells if they exist
    - Creates parent "BatteryCells" GameObject
    - Creates numberOfCells cube primitives
    - Positions them horizontally
    - Creates materials with emission
    - Stores references

void Update()
    - Checks if blinking should be active
    - Calls UpdateBlinking() when charge < 30%

void UpdateBatteryLevel(float chargePercentage)
    - PUBLIC: Called by DrillBatterySystem
    - Clamps charge to 0-1 range
    - Calculates active cells
    - Updates all cell materials
    - Sets colors and emission

void UpdateBlinking()
    - Animates emission intensity
    - Uses sine wave for smooth oscillation
    - Applies to all active cells

Color GetColorForCharge(float charge)
    - Returns appropriate color based on thresholds
    - Green/Yellow/Red/Empty

float GetEmissionIntensityForCharge(float charge)
    - Returns emission intensity for current charge
    - Matches color thresholds

void OnDestroy()
    - Cleans up created materials
    - Prevents memory leaks


═══════════════════════════════════════════════════════════════════════
INTEGRATION
═══════════════════════════════════════════════════════════════════════

DrillBatterySystem calls UpdateBatteryLevel() every frame:

    void UpdateIndicator()
    {
        if (batteryIndicator != null)
        {
            batteryIndicator.UpdateBatteryLevel(GetChargePercentage());
        }
    }

This updates the visual cells based on current battery charge.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

CELLS NOT VISIBLE:
────────────────────────────────────────────────────────────────────────
□ Cells only exist in Play mode!
□ Expand BatteryPack in Hierarchy to see "BatteryCells"
□ Adjust cellOffset to position them outside battery mesh
□ Increase cellSize to make them bigger
□ Increase emission intensity (try 5 or 10)

CELLS IN WRONG PLACE:
────────────────────────────────────────────────────────────────────────
□ In Play mode, select BatteryCells to see position
□ Adjust cellOffset: (0, 0, 0.02) moves forward
□ Scene view: zoom in to battery to find cells

CELLS NOT GLOWING:
────────────────────────────────────────────────────────────────────────
□ Verify URP is enabled in project
□ Check emission intensity is high (3-5)
□ Ensure proper lighting in scene

CELLS NOT UPDATING:
────────────────────────────────────────────────────────────────────────
□ Verify DrillBatterySystem has reference to BatteryLevelIndicator
□ Check batteryIndicator field is assigned
□ Enable debug logs to see charge updates

TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════

SHADER:
────────────────────────────────────────────────────────────────────────
Uses: "Universal Render Pipeline/Lit"
Enabled: _EMISSION keyword
Properties: _BaseColor, _EmissionColor

MATERIALS:
────────────────────────────────────────────────────────────────────────
One material per cell (6 total)
Each material is unique instance
Allows independent color/emission control

PRIMITIVES:
────────────────────────────────────────────────────────────────────────
Type: Cube (PrimitiveType.Cube)
Colliders removed (not needed)
Transform: localScale used for size

CLEANUP:
────────────────────────────────────────────────────────────────────────
OnDestroy() destroys all created materials
Prevents memory leaks
