═══════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

AUTOMATIC SETUP:
────────────────────────────────────────────────────────────────────────

When you enter Play mode, the system automatically:
    1. Creates 6 small cube objects (cells) inside BatteryPack
    2. Arranges them in a row
    3. Makes them glow with emission
    4. Updates colors based on battery charge


BATTERY DRAINS:
────────────────────────────────────────────────────────────────────────

As battery drains:
    100% → 🟢🟢🟢🟢🟢🟢  All cells green
    80%  → 🟢🟢🟢🟢🟢⚫  Right cell turns off
    60%  → 🟢🟢🟢🟢⚫⚫  Another cell off, color → yellow
    40%  → 🟡🟡⚫⚫⚫⚫  Half cells off
    30%  → 🟡🟡⚫⚫⚫⚫  Color → red
    20%  → 🔴⚫⚫⚫⚫⚫  ONE red cell blinking!
    0%   → ⚫⚫⚫⚫⚫⚫  All dark

CUSTOMIZATION
═══════════════════════════════════════════════════════════════════════

Select BatteryPack → BatteryLevelIndicator component:

[Cell Settings]
────────────────────────────────────────────────────────────────────────
Number Of Cells: 6           ← More cells = finer resolution
Cell Size: (0.01, 0.02, 0.008)  ← How big each cell is
Cell Spacing: 0.012          ← Distance between cells
Cell Offset: (0, 0, 0)       ← Position offset from center

[Battery Colors]
────────────────────────────────────────────────────────────────────────
High Charge Color: Green (0, 1, 0)      → 60-100%
Medium Charge Color: Yellow (1, 1, 0)   → 30-60%
Low Charge Color: Red (1, 0, 0)         → 0-30%
Empty Color: Dark Gray (0.2, 0.2, 0.2)  → Empty cells

[Emission Settings]
────────────────────────────────────────────────────────────────────────
High Charge Emission: 3      ← Very bright green glow
Medium Charge Emission: 2    ← Medium yellow glow
Low Charge Emission: 1.5     ← Dimmer red glow
Empty Emission: 0.2          ← Barely visible when empty

[Animation]
────────────────────────────────────────────────────────────────────────
☑ Enable Blink When Low      ← Red cells blink
Blink Speed: 3               ← How fast they blink

[Auto Setup]
────────────────────────────────────────────────────────────────────────
☑ Auto Create Cells          ← Creates cells automatically


═══════════════════════════════════════════════════════════════════════
POSITIONING THE CELLS
═══════════════════════════════════════════════════════════════════════

If cells are not visible or in wrong position:

1. ENTER PLAY MODE FIRST
   (Cells only exist in Play mode!)

2. Select "BatteryPack" in Hierarchy

3. Expand to see "BatteryCells" child

4. Adjust "Cell Offset" in Inspector:
   
   Move forward:  Cell Offset: (0, 0, 0.01)
   Move back:     Cell Offset: (0, 0, -0.01)
   Move up:       Cell Offset: (0, 0.01, 0)
   Move down:     Cell Offset: (0, -0.01, 0)
   Move right:    Cell Offset: (0.01, 0, 0)
   Move left:     Cell Offset: (-0.01, 0, 0)

5. Stop Play mode and cells will regenerate with new offset next time!


ADJUST SIZE:
────────────────────────────────────────────────────────────────────────

Cell Size controls dimensions:
    (width, height, depth)

Bigger cells:     (0.015, 0.03, 0.012)
Smaller cells:    (0.008, 0.015, 0.006)
Thinner cells:    (0.01, 0.02, 0.004)  ← Like bars
Taller cells:     (0.01, 0.03, 0.008)


ADJUST SPACING:
────────────────────────────────────────────────────────────────────────

Cell Spacing controls gap between cells:

Closer together:  0.008
Further apart:    0.02
Touching:         (same as cell width)

DEBUGGING
═══════════════════════════════════════════════════════════════════════

CELLS NOT VISIBLE:
────────────────────────────────────────────────────────────────────────
□ Are you in Play mode? (Cells only exist during play!)
□ Check Cell Size is not too small: try (0.02, 0.03, 0.01)
□ Adjust Cell Offset to position them outside battery mesh
□ Check Emission Intensity is high enough: try 5

CELLS IN WRONG LOCATION:
────────────────────────────────────────────────────────────────────────
□ Adjust Cell Offset - move them to visible area
□ In Play mode, select BatteryCells parent to see location
□ Try rotating cell offset or changing position

CELLS NOT GLOWING:
────────────────────────────────────────────────────────────────────────
□ Check Emission Intensity is high (try 5 or 10)
□ Verify your scene has proper lighting for URP
□ Check Global Illumination is enabled

TESTING:
────────────────────────────────────────────────────────────────────────

2. Select DummyDrill-Rigged
