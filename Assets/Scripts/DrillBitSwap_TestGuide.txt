DRILL BIT SWAP - TEST GUIDE
═══════════════════════════════════════════════════════════════════════

How to test that heat effects correctly transfer between drill bits

SETUP:
────────────────────────────────────────────────────────────────────────
Make sure you have:
✓ DrillHeatSystem component on DummyDrill-Rigged
✓ Multiple drill bits in your scene (3mm, 5mm, 8mm, 10mm)
✓ SG_TriggerLogic properly configured for bit swapping

═══════════════════════════════════════════════════════════════════════
TEST 1: Basic Drill Bit Swap
═══════════════════════════════════════════════════════════════════════

STEP 1: Start drilling with initial drill bit
────────────────────────────────────────────────────────────────────────
1. Press Play
2. Grab the drill
3. Note which drill bit is currently attached (e.g., "3mm drill bit")
4. Start drilling into the wooden table
5. Keep drilling for 10-15 seconds

EXPECTED RESULT:
    ✓ Heat increases
    ✓ Drill bit starts glowing orange
    ✓ At 50%: Yellow burning smell wisps appear
    ✓ At 70%: Gray smoke appears
    ✓ Drill bit glowing bright red

STEP 2: Swap to different drill bit (while hot)
────────────────────────────────────────────────────────────────────────
1. While drill is still hot (red glow visible)
2. Swap to a different drill bit (e.g., 5mm drill bit)
3. Observe BOTH drill bits

EXPECTED RESULT:
    ✓ OLD drill bit (3mm): Returns to normal gray color
    ✓ NEW drill bit (5mm): Immediately shows red glow
    ✓ Point light moves to new drill bit
    ✓ Smoke particles move to new drill bit position
    ✓ Heat value stays the same (e.g., still 80%)

STEP 3: Continue drilling with new bit
────────────────────────────────────────────────────────────────────────
1. Start drilling with the new drill bit
2. Watch as heat continues to increase

EXPECTED RESULT:
    ✓ New drill bit continues to glow brighter
    ✓ Smoke continues from new drill bit
    ✓ Old drill bit stays normal (no glow)

═══════════════════════════════════════════════════════════════════════
TEST 2: Multiple Rapid Swaps
═══════════════════════════════════════════════════════════════════════

1. Heat up the drill to 100% (maximum red glow)
2. Rapidly swap between different drill bits:
   - 3mm → 5mm → 8mm → 10mm → 3mm

EXPECTED RESULT:
    ✓ Each drill bit shows red glow when active
    ✓ Each drill bit returns to normal when swapped out
    ✓ No lingering glow on inactive bits
    ✓ Point light always follows active drill bit
    ✓ No errors in Console

═══════════════════════════════════════════════════════════════════════
TEST 3: Cool Down After Swap
═══════════════════════════════════════════════════════════════════════

1. Heat up drill to 80% (orange-red glow)
2. Swap to different drill bit
3. STOP drilling (release trigger)
4. Watch as heat decreases

EXPECTED RESULT:
    ✓ New drill bit glow fades from red → orange → gray
    ✓ Old drill bit stays normal
    ✓ At 70%: Smoke stops
    ✓ At 50%: Burning smell stops
    ✓ At 0%: All effects off, new bit is normal gray

═══════════════════════════════════════════════════════════════════════
TEST 4: Swap While Cool
═══════════════════════════════════════════════════════════════════════

1. Start with cool drill (0% heat)
2. Swap between drill bits without drilling

EXPECTED RESULT:
    ✓ All drill bits stay normal gray color
    ✓ No glow effects
    ✓ Point light follows active drill bit but stays off (0 intensity)
    ✓ No particles

DEBUGGING TIPS
═══════════════════════════════════════════════════════════════════════

If old drill bit still glows after swap:
    1. Select DummyDrill-Rigged
    2. Check DrillHeatSystem in Inspector
    3. Verify "Material Index" is correct (usually 0)
    4. Check Console for errors
    5. Make sure script has been recompiled

If new drill bit doesn't glow:
    1. Check that new drill bit has a Renderer
    2. Check that material has "_EmissionColor" property
    3. Verify "Use Emission Glow" is checked
    4. Check heat value is actually > 0

Watch in Inspector while swapping:
    1. Select DummyDrill-Rigged
    2. Expand DrillHeatSystem component
    3. Look at "Drill Bit Tip" reference
    4. It should change when you swap bits
    5. Heat value should persist across swaps
